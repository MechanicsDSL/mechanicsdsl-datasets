# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.2.x   | yes       |
| < 0.2   | no        |

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Email
**mechanicsdsl.project@gmail.com** with a description, the affected version,
and steps to reproduce. You should get an acknowledgement within 7 days.

## Scope notes

`mechanicsdsl-datasets` turns DSL specifications into source code. Treat a
DSL spec like any other code you run: generated output embeds expressions
from the spec verbatim, so only compile specs you trust.
